# 关于本项目

## 项目目标

把 Markdown 文档变成可以在浏览器中访问的网站，并在文档更新后自动构建和发布。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写标题、列表、表格和示例代码 |
| MkDocs Material | 根据配置生成导航和静态网页 |
| GitHub Actions | 安装依赖、构建网站并执行部署 |
| GitHub Pages | 托管构建完成的网页 |

源文档放在 `docs/` 中，构建产物放在 `site/` 中。需要更新网站时，修改源文档后重新构建即可。

## 部署实践记录

首次运行时，仓库还没有启用 Pages。把发布来源设为 GitHub Actions 后重新运行，构建和发布都成功了。第二次只改了首页，推送后就出现了一次新的 Actions 运行，随后公开页面也显示了新增内容。这次检查把提交记录、工作流状态和网页内容对应了起来。
